# 화면 캡처

2026-10-15에 배포된 UI(`2100a43`)를 기준으로 한 README용 화면입니다. viewport는 375 × 812px이며 Playwright Chromium으로 캡처했습니다.

기존 UI 검사에서 촬영한 PNG를 그대로 보관하고, 내 계정·성장 기록·활동 알림·자료 이전 미리보기를 추가 촬영했습니다. 공개 배포 사이트의 실제 UI를 사용하되 Supabase 요청은 테스트 fixture로 대체했습니다. 테스트 계정·샘플 펫을 사용하며 실제 이용자 개인정보와 비공개 사진은 포함하지 않습니다. 일부 사진은 테스트 색상 이미지 또는 로딩 실패 시 대체 화면입니다. 서버 동작 검증의 증거와 화면 예시는 구분합니다.

이미지를 합성하거나 UI를 이미지 편집으로 변경하지 않았습니다. 파일은 저장소에 포함되어 GitHub README에서도 상대 경로로 표시됩니다.
