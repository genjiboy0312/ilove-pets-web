# 짧은 시연 영상

2026-10-15 로컬 production 빌드의 세 가지 대표 흐름입니다. [영상 모아 보기](index.html)를 로컬 브라우저에서 열면 재생할 수 있습니다. GitHub에서는 아래 파일 링크를 열거나 내려받아 확인합니다.

| 순서 | 영상                                   | 보여 주는 흐름                                           | 촬영 조건                       |
| ---- | -------------------------------------- | -------------------------------------------------------- | ------------------------------- |
| 1    | [기기 기록](01-device-journal.webm)    | 비로그인 안내 → 펫 등록 → 사진 일기 → 홈 → 새로고침 유지 | 실제 브라우저 저장, 새 컨텍스트 |
| 2    | [공개 소통](02-public-social.webm)     | 공개 글 → 좋아요 → 댓글 → 새로고침 → 공개 프로필         | 테스트 계정·모의 API            |
| 3    | [안전과 복구](03-safety-recovery.webm) | 신고 → 429 → 재시도 → 접수 → 차단 영향·재확인            | S5 미배포 작업본·모의 API       |

390 × 844px Chromium 모바일·터치 에뮬레이션, 한국어·라이트 테마로 녹화했습니다. 음성은 없으며 녹화 전용 자막을 화면 위에 표시했습니다. 자막은 제품 UI에 포함되지 않습니다. 첫 영상의 사진은 프로젝트 AI 생성 동물 가족 일러스트이며, 소셜 영상의 단색 이미지는 테스트 fixture입니다. 개인 사진·실제 이용자 정보·실제 로그인 세션은 사용하지 않았습니다.

모든 미일치 외부 네트워크 요청을 차단했고, 신고·차단·댓글을 실제 Supabase에 전송하지 않았습니다. 두 번째 영상은 전체 실제 계정 A/B·알림 흐름의 증거가 아니며 세 번째 영상은 S5가 공개 운영 중임을 뜻하지 않습니다. 시간 제한 오류는 다음 요청이 성공하도록 테스트로 통제했습니다. 운영 환경의 제한이 2.6초 후 자동으로 풀린다는 뜻이 아닙니다.

## 다시 촬영하기

영상 길이는 약 26초·18초·20초이며 총 약 64초입니다. 표지 PNG는 각 영상의 8초 프레임을 디코딩한 이미지입니다. 촬영 자막 외에 화면을 합성하지 않았습니다. [재생 파일 정보](metadata.json)에 길이·해상도와 디코딩 확인 날짜를 남겼습니다. `demo:record`는 녹화 성공 후 표지와 메타데이터도 갱신합니다.

```bash
npm run build
npm run demo:record
```

공개 Supabase 환경변수가 있는 로컬 빌드와 Playwright Chromium이 필요합니다. 서버 응답은 [기존 소셜 fixture](../../tests/support/social-fixture.ts)와 [시연 스크립트](../../tests/portfolio/scenarios.demo.ts)에서 재현합니다. 전용 포트는 5178이며 이미 사용 중이면 실패하도록 설정했습니다. WebM 세 파일을 갱신하므로 검토 후 커밋합니다. SMTP·OAuth Client Secret·관리자 키는 필요하지 않습니다.
