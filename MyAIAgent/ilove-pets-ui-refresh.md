# 전체 페이지 UI 정리

2026-10-15. 사용자가 확인한 카테고리·My 디자인을 기준으로 나머지 페이지를 정리했다.

## 적용 범위

- 홈: 스토리 영역, 피드 전환 탭, 게시물 카드·반응 영역.
- 탐색: 검색 아이콘과 입력창, 게시물/릴스 탭, 가로 인기 펫 목록, 사진 그리드.
- 커뮤니티: 게시판/지도 전환, 카테고리 칩, 게시글 카드, 병원 필터·목록·지도 프레임.
- 작성: 저장 위치와 본문을 같은 페이지 컨테이너에 배치하고 사진 선택·입력창·버튼을 정리.
- 로그인/가입/복구: 브랜드 영역, 모드 선택, 입력과 제출 버튼.
- 활동·설정: 알림·로그인 안내·빈 상태 카드, 설정 그룹·목록·선택 시트.
- 공개 프로필·게시물 상세·클라우드 기록·자료 이전과 댓글·공유·스토리 작성 팝업의 공통 표면과 입력 컨트롤.

기존 테마 색상과 아이콘 체계를 사용한다. 공통 스타일은 `discovery.css`, `workspace.css`에서 관리하고, 승인된 My 스타일은 그 뒤에 적용한다. 입력 필드에는 16px 글자를 사용한다. 인증·데이터 저장·권한 API 계약은 바꾸지 않았다.

## 검증

- 앱 단위 검사 38개 파일/192개 통과.
- Chromium 전체 70개 중 69개 통과 후, 프로필 이동 완료를 기다리는 선택자를 보완하고 관련 19개를 재검사해 통과했다. 탐색 가로 목록은 상위 컨테이너의 최소 너비를 제한해 페이지 넘침을 수정했다.
- 일본어 커뮤니티의 긴 목록은 스크롤 마지막에서 콘텐츠가 고정 내비게이션 위에 보이는지 검사한다. 모든 목록이 첫 화면에 들어가야 한다는 이전 가정을 제거했다.
- 11개 화면의 라이트·다크 캡처 및 ko/en/ja·375/768/1280px 페이지/병원 지도 너비 검사를 5개 별도 브라우저 검사로 통과했다. 화면 검사에는 모의 API를 사용하며 실물 휴대전화 검증과 구분한다.
- 타입 검사·변경 파일 린트·포맷과 별도 출력 폴더 production build를 확인했다. 기존 Windows dist 파일 잠금과 번들 크기 경고는 후속 과제다.

## 로그인 진입과 카테고리 후속 정리

2026-10-15. 비로그인 내 계정은 로그인 안내를 기본 화면으로 제공한다. Google·이메일 진입과 로그인 필요 설명을 표시하고 프로필·펫·게시물·스토리 관리는 숨긴다. 기기 기록은 보조 버튼으로 명시적으로 선택하며 `?destination=local`로 접근한다. 안내로 돌아가거나 새로 진입해도 기존 자료는 삭제하지 않는다. 작성 화면의 첫 펫 등록 링크는 기기 관리로 직접 연결한다. 인증 확인 중에는 로딩만 표시한다. 한국어·영어·일본어 문구를 추가했다.

카테고리는 별도 좌우 화살표를 제거하고 하나의 둥근 바 안에서 선택 항목만 강조한다. 가로 스크롤과 양끝 그라데이션으로 넘길 수 있음을 표시하고, 방향키·Home·End로 초점을 이동한다. 선택은 Enter·Space 또는 클릭으로 확정한다. 선택 항목과 키보드 초점은 보이는 범위로 이동하며 ResizeObserver로 너비 변화를 반영한다.

검증: 앱 39개 파일·194개 통과. Chromium 관련 47개 통과(기기 자료 보존, 인증·프로필, 성장 수정, 백업·복원, 오프라인, 3개 언어·라이트/다크·375/768/1280px 포함). 타입 검사·변경 파일 린트·production 빌드를 확인했다. 서버 계약은 변경하지 않았다. 브라우저 화면 검사는 실물 휴대전화 또는 실제 Google 인증의 재검증과 구분한다. 홈·비로그인 내 계정 캡처와 README 진입 시나리오를 갱신했다.

## 동물 가족 일러스트

2026-10-15. 비로그인 내 계정의 발바닥 아이콘을 웰시코기·고양이·도마뱀·토끼·새·햄스터 6마리의 AI 생성 가족 일러스트로 교체했다. 내장 이미지 생성 도구를 사용했고 원본과 최종 프롬프트는 `assets/README.md`에 기록했다. 웹용은 투명 alpha를 유지한 768×512 WebP 74,818 bytes이며 원본 PNG도 보관한다. UI는 최대 너비 272px·높이 168px로 제한해 버튼과 기기 기록 진입 공간을 확보한다. 장식 이미지의 alt는 비워 둔다.

타입 검사·변경 파일 린트·production 빌드와 관련 Chromium 5개 검사를 통과했다. 브라우저 캡처 전에 이미지의 실제 로딩 완료도 확인한다. ko/en/ja·라이트/다크·375/768/1280px를 확인했고 README의 비로그인 내 계정 캡처 2장을 갱신했다.
