# 전체 페이지 UI 정리

2026-10-15. 사용자가 확인한 카테고리·My 디자인을 기준으로 나머지 페이지를 정리했다.

## 적용 범위

- 홈: 스토리 영역, 피드 전환 탭, 게시물 카드·반응 영역.
- 탐색: 검색 아이콘과 입력창, 게시물/릴스 탭, 가로 인기 펫 목록, 사진 그리드.
- 커뮤니티: 게시판/지도 전환, 카테고리 칩, 게시글 카드, 병원 필터·목록·지도 프레임.
- 작성: 저장 위치와 본문을 같은 페이지 컨테이너에 배치하고 사진 선택·입력창·버튼을 정리.
- 로그인/가입/복구: 브랜드 영역, 모드 선택, 입력과 제출 버튼.
- 활동·설정: 알림·로그인 안내·빈 상태 카드, 설정 그룹·목록·선택 시트.
- 공개 프로필·게시물 상세·클라우드 기록·자료 이전과 댓글·공유·스토리 작성 팝업의 공통 표면과 입력 컨트롤.

기존 테마 색상과 아이콘 체계를 사용한다. 공통 스타일은 `discovery.css`, `workspace.css`에서 관리하고, 승인된 My 스타일은 그 뒤에 적용한다. 입력 필드에는 16px 글자를 사용한다. 인증·데이터 저장·권한 API 계약은 바꾸지 않았다.

## 검증

- 앱 단위 검사 38개 파일/192개 통과.
- Chromium 전체 70개 중 69개 통과 후, 프로필 이동 완료를 기다리는 선택자를 보완하고 관련 19개를 재검사해 통과했다. 탐색 가로 목록은 상위 컨테이너의 최소 너비를 제한해 페이지 넘침을 수정했다.
- 일본어 커뮤니티의 긴 목록은 스크롤 마지막에서 콘텐츠가 고정 내비게이션 위에 보이는지 검사한다. 모든 목록이 첫 화면에 들어가야 한다는 이전 가정을 제거했다.
- 11개 화면의 라이트·다크 캡처 및 ko/en/ja·375/768/1280px 페이지/병원 지도 너비 검사를 5개 별도 브라우저 검사로 통과했다. 화면 검사에는 모의 API를 사용하며 실물 휴대전화 검증과 구분한다.
- 타입 검사·변경 파일 린트·포맷과 별도 출력 폴더 production build를 확인했다. 기존 Windows dist 파일 잠금과 번들 크기 경고는 후속 과제다.
